◈ HYBRID NIDS - CLOSED-LOOP SYSTEM

THREE-LAYER ARCHITECTURE

This Hybrid NIDS uses a closed-loop architecture with continuous learning:

  • Layer 1 - The Reflex: High-speed rule-based detection using YARA and Snort-style signatures. Catches known attacks instantly.
  • Layer 2 - The Brain: ML-based anomaly detection using statistical analysis. Detects new/unknown attacks by analyzing behavior patterns.
  • Layer 3 - The Teacher: Learning engine that automatically creates new rules from ML detections, closing the loop for continuous improvement.

HOW ML IS UTILIZED

The system uses statistical ML for real-time anomaly detection:

  • Feature Extraction: Extracts 13 features per IP (packet rate, port diversity, connection rate, etc.)
  • Anomaly Scoring: Uses threshold-based scoring to identify suspicious patterns
  • Attack Types Detected: Port scans, SYN floods, DDoS, DNS amplification, ICMP floods
  • Why Statistical ML: Lightweight, real-time, no training required - ideal for network security

HOW IT WORKS

The Closed-Loop Detection Process:

  • Traffic arrives: Packet is checked by Layer 1 (rules)
  • If known: Blocked immediately (fast path)
  • If unknown: Sent to Layer 2 (ML analysis)
  • If suspicious: Layer 3 auto-generates a new rule
  • Rule deployed: Added to Layer 1 for faster detection next time

DETECTION RULES

Rules are defined in rules.txt using Snort syntax. Each rule specifies:

  • action - What to do when matched (alert, log, drop)
  • protocol - TCP, UDP, ICMP, or any
  • source/destination - IP addresses and ports
  • options - Content matching, flags, etc.

YARA RULES

YARA rules in yara_rules/ folder detect malware patterns. Rules use:

  • Strings: Hex or text patterns to find
  • Condition: Logic to trigger detection
  • Metadata: Information about the rule
